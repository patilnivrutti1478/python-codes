# Student Data Analysis using Python

## Project Overview
This project analyzes student marks data using Python and Pandas.

## Features
- Read CSV data
- Display records
- Calculate average marks
- Find highest and lowest marks
- Generate Bar Chart
- Generate Pie Chart

## Technologies Used
- Python
- Pandas
- Matplotlib

## Files
- Data.csv
- main.py
- Bar chart.png
- pie chart.png
